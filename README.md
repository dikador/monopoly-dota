# ⚔️ Монополия: Dota 2

Онлайн-«Монополия» для игры с друзьями. Тема доски — **Dota 2**: клетки-герои
(Pudge, Invoker, Anti-Mage…), вокзалы → башни, лавки → магазины, тюрьма → респаун,
налоги → выкуп (buyback), карточки → руны и курьер, валюта → золото 🪙.
Интерфейс полностью на русском.

## Возможности

- Игра по сети: создаёте комнату, друзья заходят по коду или ссылке.
- 2–8 игроков, у каждого своя фишка и цвет.
- Полные правила: покупка, аренда, **дома и отели**, **ипотека (залог)**,
  **респаун**, карточки «Руна» и «Курьер», **аукционы**, **сделки между игроками**,
  **похвала (commend) со звуком и уведомлением**,
  **банкротство** и определение победителя.
- Красивая доска, анимация кубиков, журнал событий и чат.
- Авто-переподключение по имени, если кого-то выбросило из сети.

## Запуск локально

```bash
cd monopoly
npm install
npm start
```

Откройте `http://localhost:3000`. Друзья в той же Wi-Fi сети заходят по
адресу `http://<ваш-IP>:3000` (узнать IP: `ipconfig` в Windows).

## 🎮 Игра с друзьями через интернет — деплой на Render (рекомендуется)

Постоянная быстрая ссылка, **без туннеля и без вашего ПК** — минимальная задержка.

1. **Загрузите папку `monopoly` в GitHub** как отдельный репозиторий
   (папка `monopoly` должна быть корнем репозитория — внутри неё `package.json`).
   ```bash
   cd monopoly
   git init
   git add .
   git commit -m "monopoly dota"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/monopoly-dota.git
   git push -u origin main
   ```
2. Зайдите на [render.com](https://render.com) → войдите через GitHub.
3. **New +** → **Web Service** → выберите свой репозиторий.
   Render сам прочитает `render.yaml`; если спросит вручную:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. **Create Web Service**. Через пару минут получите постоянную ссылку
   вида `https://monopoly-dota.onrender.com`.
5. Откройте ссылку, создайте игру и пришлите друзьям ссылку-приглашение
   с экрана ожидания. Играть можно когда угодно — ПК включать не нужно.

> На бесплатном тарифе сервис «засыпает» после ~15 мин простоя: первая
> загрузка после паузы занимает ~30–60 сек, дальше всё быстро.

## Быстрый туннель (если деплой пока не нужен)

На вашем ПК (есть задержка из-за relay-сервера туннеля):
```bash
cd monopoly
npm install
npm run online      # выдаст ссылку https://...loca.lt + пароль для друзей
```
Окно не закрывайте, пока играете (выход — Ctrl+C). Для друзей в одной Wi-Fi
сети — просто `npm start` и адрес `http://ВАШ-IP:3000` (задержки нет).

## Как играть

1. Введите имя → **Создать игру** (вы становитесь хостом).
2. Передайте друзьям 4-значный **код** или **ссылку** со страницы ожидания.
3. Когда все зашли — хост нажимает **Начать игру**.
4. В свой ход: бросьте кубики, покупайте/торгуйтесь, стройте дома,
   затем **Завершите ход**. Клик по любой клетке открывает её карточку с ценами.

Приятной игры! 🚀
